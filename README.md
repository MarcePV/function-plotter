Desmos-like function plotter in Raylib C

Shows FPS, Zoom %, and it was optimized to be ```25x faster``` than plotting a lot of small points through the use of line approximations. I plotted less points and then drew lines to connect them to approximate continuinity. 

Avg FPS on my machine = 200 FPS
